Information

PQ-Registration is a data viewer for grouting injection and Lugeon test registrations: import measurement files, review and annotate them, chart pressure / flow / quantity, produce reports and export CSV.

This is an unofficial web re-creation of the desktop application “PQ-Registration V5” by SPÄNI Elektro-Mechanik AG for Häny Mixing and Injection Technology AG (www.haeny.com). It is not affiliated with or endorsed by them.
